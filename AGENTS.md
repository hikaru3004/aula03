# Projeto - Sistema de Acompanhamento de Notas

## Stack
- Python 3.10+
- Biblioteca padrão (`json`, `math`, `sys`)

## Comandos
- testar: pytest
- rodar: python main.py

## Convenções
- Salvar dados JSON no diretório `data/`
- Separar lógica de negócios (cálculos) da interface CLI

## Nunca
- Não utilizar bibliotecas externas nem frameworks web (manter estritamente em CLI + JSON)

> Auditado: Defeito 'Lint Leakage' corrigido ao remover regras de formatação (PEP8) cobertas pelo linter.
